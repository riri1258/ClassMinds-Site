API Keys
OpenAI, Deepgram, and OneSignal keys are stored in Google Cloud Secret Manager and bound to Cloud Functions at deploy time. They are never written to Firestore.
To rotate a key, run from the project root:
firebase functions:secrets:set OPENAI_KEY
firebase functions:secrets:set DEEPGRAM_KEY
firebase functions:secrets:set ONESIGNAL_API_KEY
firebase deploy --only functions
