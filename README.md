# ClassMinds

> AI tutor that knows your notes. Per-class chat. Deadline tracking.
> Built for college students on iOS.

🌐 **Website**: https://classminds.app
📱 **Beta**: TestFlight (free during beta)
💰 **Price**: $8.99/month after launch

## What it does

- **AI Tutor** — answers questions using your own lecture slides + notes, cites the source
- **Class Chat** — auto-created group chat per class, scoped to your section
- **Class Hub** — assignments, deadlines, notes, slides per course
- **Schedule Import** — snap a photo of your registrar page, done in 90 seconds
- **Smart Reminders** — deadline + @-mention only, respects iOS Focus

## Privacy

User notes are never used to train any AI model. Encrypted at rest. Account deletion permanently wipes personal data.
